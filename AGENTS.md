# 2GIS Drift — правила проекта

## Направление

- Развивать игру в браузере на странице 2ГИС через Chromium-расширение Manifest V3 для Chrome/Edge. Настольное приложение больше не развивать; существующую сборку не изменять.
- Максимально переиспользовать существующую физику, камеру, столкновения и игровую логику. Не переписывать их без конкретной необходимости.
- Сохранять текущую интеграцию с картой 2ГИС. Переход на отдельный сайт с другой интеграцией карты не согласован.

## ShadowPass и мультиплеер

- Использовать ShadowPass как планируемый сервер для конфигурации, ресурсов и будущих экспериментов с мультиплеером.
- Выносить на сервер данные, которые можно менять без выпуска расширения: проверяемые параметры физики, флаги возможностей, модели, текстуры, звуки, задания, сведения о комнатах и состоянии игроков.
- Исполняемый движок и интеграция с картой остаются в пакете расширения. Не загружать с ShadowPass/GitHub удалённый JavaScript или WebAssembly для исполнения и не обходить ограничения магазина через eval или интерпретируемые команды.
- Для серверных данных предусматривать версию формата, проверку типов и диапазонов и безопасные локальные значения при недоступности сервера. Данные не должны становиться каналом доставки произвольного кода.
- Мультиплеер запланирован, но пока не реализован. WebSocket — рассматриваемый транспорт; модель синхронизации и серверная авторитетность ещё не выбраны.

## Обновления

- Предпочтительный канал автоматического обновления кода — Chrome Web Store / Microsoft Edge Add-ons.
- GitHub Releases содержит установочный ZIP и SHA-256. Unpacked-установка требует обновить локальные файлы и вручную перезагрузить расширение; не обещать ей автоматическое обновление кода.
- Серверные ресурсы и настройки могут обновляться независимо от версии расширения, в пределах поддерживаемого формата. Сообщать отдельно, что уже реализовано, а что только запланировано.

## Репозиторий и проверки

- Публиковать только необходимую браузерную версию; не включать Electron, готовое приложение, HAR, дампы, выгрузки карты, cookies, профили, секреты или локальные журналы.
- Сохранять сторонние лицензии и атрибуцию ресурсов. Не распространять данные или код 2ГИС как часть проекта.
- Все файлы родительской папки `sources/` — синхронизированные справочные материалы только для чтения; не изменять, не перемещать и не удалять их.
- После изменений выполнять соответствующие проверки. Изменения worker-интеграции и игрового поведения проверять на живой карте; не заявлять проверку магазина или Edge, если её не было.
