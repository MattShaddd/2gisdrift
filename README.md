# 2GIS Drift

Неофициальный эксперимент: автомобиль, физика, столкновения и камера на живой карте 2ГИС. Работает в браузере, без настольного приложения и ручной вставки скриптов. Нужен интернет. Проект не связан с 2ГИС; изменения внутренних API карты могут сломать игру. Мультиплеер отсутствует.

## Установка Chrome / Edge на другом компьютере

1. Скачайте `2gisdrift-extension.zip` из [GitHub Releases](https://github.com/MattShaddd/2gisdrift/releases/latest) и распакуйте в постоянную папку. Не загружайте ZIP непосредственно в браузер.
2. Откройте `chrome://extensions` или `edge://extensions`, включите режим разработчика → «Загрузить распакованное расширение» → выберите папку с `manifest.json`.
3. Откройте https://2gis.ru/novosibirsk и закрепите значок расширения.
4. Нажмите значок. **Карта перезагрузится**, чтобы подключить код столкновений к её worker-потокам. Дождитесь `ON` на значке; подготовка может занять до 90 секунд.
5. Повторное нажатие останавливает игру и перезагружает карту. Для временной паузы используйте F8 или Esc.

Расширение использует `activeTab` и `debugger`, без постоянного доступа ко всем сайтам. `debugger` — широкое разрешение браузера; наш код подключается только к выбранной вкладке `https://2gis.ru`, после нажатия пользователем. Браузер показывает уведомление об отладке — это ожидаемо. DevTools может прервать подключение. Если закрыли уведомление/отладку вручную, перезагрузите карту, чтобы убрать игровую логику. При `ERR` наведите курсор на значок для текста ошибки; остановите и запустите снова. Chrome/Edge 125+.

## Управление

Начиная с 0.1.2, близкая камера сохраняет нативную воду выше масштаба 22, а ближняя плоскость отсечения подстраивается под расстояние до машины: земля и кузов больше не срезаются при сильном приближении. Исправления используют внутренние API карты, как и существующая интеграция; обновления 2ГИС могут потребовать адаптации. Параметры камеры настраиваются в панели игры; физика не изменена.

WASD / стрелки — движение; Пробел — ручник; B — выбрать место на карте; R — восстановить; F — слежение камеры; правая кнопка — вращение; F8 — пауза; Esc — выйти из управления. Настройки машины справа внизу. Настройки сохраняются в локальном хранилище страницы 2ГИС. При выборе города через карту игра использует подгружаемые данные нового места.

## Разработка

Нужны Git и Node.js 24+. Зависимостей для сборки нет.

```powershell
git clone https://github.com/MattShaddd/2gisdrift.git
cd 2gisdrift
npm run build
npm run check
```

Загрузите папку `extension` как распакованное расширение. После изменения `src/game` повторите сборку, нажмите «Обновить» у расширения и перезагрузите карту.

Необязательная интеграционная проверка живой карты: `npm install --no-save --package-lock=false playwright`, `npx playwright install chromium`, `node scripts/qa-browser.cjs`. Использует отдельный временный профиль браузера. Проверяет запуск через тот же обработчик, что нажатие значка, worker-потоки, движение, паузу, спавн, перезагрузку и остановку. Для выбранной установки Chromium задайте `DRIFT_CHROMIUM` с путём к исполняемому файлу. Это не проверка сертификации магазина или отдельной установки Edge.

- `src/game/` — исходная готовая игровая логика и встроенная модель, перенесённые без изменения из рабочей версии; физика не переписана.
- `extension/` — MV3, обработка нажатия и адаптер к worker-потокам карты. `extension/game/` создаётся сборкой и не хранится повторно в Git.
- `scripts/` — сборка, проверка публикации, обновление dev-копии.
- `docs/` — доставка обновлений, приватность и происхождение кода.

## Публикация и обновления

С версии 0.1.1 расширение проверяет стабильные GitHub Releases при установке, запуске браузера, нажатии значка и далее раз в 15 минут, с ограничением не чаще одного сетевого запроса за 15 минут. При новой версии один раз показывает системное уведомление «Доступна версия…»; нажатие или кнопка «Открыть релиз» открывает страницу загрузки. Это только проверка метаданных, без исполнения удалённого кода. При закрытом/спящем браузере проверка откладывается; 15 минут — интервал, а не гарантия доставки. Уведомления могут быть скрыты настройками браузера/ОС.

Для этого добавлены разрешения `alarms`, `storage`, `notifications` и доступ к `https://api.github.com/*` (запросы идут только к endpoint Releases нашего репозитория). Сохраняется номер показанной версии, чтобы не повторять уведомление. Версию 0.1.0 необходимо один раз вручную заменить на 0.1.1: в старом коде проверка отсутствует. Дальнейшая установка unpacked-обновлений тоже ручная: скачайте ZIP, замените файлы в прежней папке, нажмите Reload расширения и перезагрузите карту. Репозиторий, cookies и аккаунт GitHub для проверки не требуются.

Предпочтительно Chrome Web Store / Microsoft Edge Add-ons: установленные из магазина версии обновляются браузером. ZIP из Releases — артефакт для установки и подачи в магазин, а не механизм автоматической установки Chrome. Одобрение магазина не гарантируется, особенно с разрешением `debugger`.

Для dev-копии предусмотрен явный переход на проверенный release tag:

```powershell
pwsh -File scripts/update-dev.ps1 -Tag v0.1.1
```

После этого нажмите «Обновить» расширения в браузере. Подробности и ограничения: [docs/UPDATES.md](docs/UPDATES.md).

Для релиза увеличьте версии в `package.json` и `extension/manifest.json`, закоммитьте, создайте соответствующий тег (`git tag v0.1.1`) и отправьте (`git push origin main --tags`). GitHub Actions проверит файлы и опубликует ZIP с SHA-256. На первом релизе используйте текущую версию `v0.1.0`.
