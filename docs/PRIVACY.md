# Приватность

2GIS Drift не отправляет телеметрию, аккаунты, cookies или историю на отдельный сервер. Подключение отладчика используется для исполнения включённых в расширение игровых файлов и связи с worker-потоками выбранной карты. Данные геометрии обрабатываются в памяти вкладки. Игра хранит настройки автомобиля в localStorage страницы 2ГИС. Сайт 2ГИС самостоятельно выполняет свои сетевые запросы и применяет свою политику приватности.

Проверка обновлений обращается к публичному GitHub API `repos/MattShaddd/2gisdrift/releases/latest` без токенов, cookies и данных вкладки. GitHub получает обычные сетевые сведения, включая IP-адрес клиента. В локальном хранилище расширения сохраняются время последней проверки и номера доступной/показанной версии. Уведомление открывает страницу релиза только после нажатия пользователем. Код из сети не загружается и не исполняется. ShadowPass для этого пока не используется.

Разрешение debugger технически широкое; ограничение выбранной страницей 2gis.ru реализовано адаптером. Исходный код доступен для проверки. Остановка через значок перезагружает вкладку и отключает отладчик.
