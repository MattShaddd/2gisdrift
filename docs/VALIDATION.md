# Проверка перед публикацией — 2026-10-13

## Версия 0.1.1 — уведомления о релизах

Проверены числовое сравнение версий, одна нотификация на релиз, объединение параллельных запросов, ограничение частоты, отказ draft/prerelease/подменённых URL, отсутствие уведомления для текущей версии, ошибки сети/JSON и ограничение GitHub API. В настоящем Chromium с unpacked-расширением проверены созданное системное уведомление, сохранённый номер показанной версии и alarm на 15 минут; ответ о будущей версии был подменён только для теста. Проверка ОС-доставки на каждом устройстве не гарантируется, уведомления могут быть выключены. Повторная полная проверка запуска и управления на живой карте прошла. Игровые исходники не изменялись.

Исходная папка проекта не была Git-репозиторием. Создан отдельный чистый репозиторий `2gisdrift`, ветка main. В него не переносились Windows-приложение, Electron, node_modules, исследовательские скрипты, HAR, GeoJSON, дампы, снимки, пользовательские настройки или профили браузера. `sources/` не изменялась.

Игровые car.js, world.js и worker.js совпадают байт-в-байт с исходной рабочей сборкой. Сохранены атрибуция модели и лицензия polygon-clipping. Встроенная модель — необходимый графический ресурс, а не локальная выгрузка карты.

`npm run build` и `npm run check`: синтаксис, Manifest V3, ограниченный список разрешений, совпадение сборки и исходников, поиск типовых токенов/приватных ключей/присвоенных credentials во всех файлах Git. Значения подозрительных данных не печатаются. Совпадений не найдено; поиск по шаблонам не гарантирует обнаружение всех форм секретов.

Живая интеграционная проверка в Chromium с загруженным unpacked расширением на 2gis.ru/novosibirsk прошла: 3 worker-подключения, 4 чанка и 1547 colliders; загрузка модели, GL error 0, движение при W, пауза F8, выбор места B, восстановление после перезагрузки страницы, остановка с удалением runtime, повторный запуск, отключение при уходе с 2GIS, отказ запуска на другом сайте. Использован отдельный временный профиль. Тест вызывает зарегистрированный обработчик action, не автоматизирует нажатие значка в панели браузера. Отдельный Edge и магазин не проверялись. GitHub Actions/магазин смогут быть проверены только после внешней публикации.

При первом запуске теста адаптер пытался сериализовать возвращённый объект карты через CDP. Исправлено только в адаптере: установочные выражения возвращают void, игровая логика не изменена.
